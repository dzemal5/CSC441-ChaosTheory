## 3. Project selection:
Recipe Book

## 4. Project description:
A categorized list of recipes, where each recipe has its own page.

## 5. Two functional tabs:
First tab would be a "main view", featuring a catalog with all of the recipes [ or perhaps just recipe categories ], second tab would be the detailed view for the recipe that the user clicks ons.

## 6. Technology:
The Android app and website are both serving as front-ends to the Supabase, which retains all of the recipes and category information. Both the app and website can pull data from the Supabase as needed.
